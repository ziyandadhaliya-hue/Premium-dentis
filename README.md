# IRONVANTA Gym Website

A premium dark/acid-green gym landing website demo.

## Included
- High-impact hero section
- Crazy custom CSS / responsive design
- Programs and pricing
- Gym photo gallery
- 6 member reviews
- Free-trial booking form
- Add Post / photo posting demo using browser localStorage
- Mobile responsive layout
- Smooth scrolling and modal interactions

## Run
Just open `index.html` in a browser.

## Important
The booking form and post system are frontend demo functionality. For a real client website, connect bookings to a backend/database, email/WhatsApp, or a booking service.
